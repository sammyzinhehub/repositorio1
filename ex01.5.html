Iniciando estudos DOM

Selecionando elementos DOM

Posso selecionar elementos DOM: por marca (tagname); por ID; po classe; por seletor (por CSS)

Existem alguns comandos que nós vamos utilizar

Por marca (tagname)

O comando é: getElementsByTagName

Como está no plural: getElements... eu preciso dizer o número do elemento que eu quero utilizar, lembrando que no JS a contagem dos elementos começa do Zero.

Por ID

O comando é: getElementById

Preciso atribuir um ID na tag que eu quero manipular

Por class

O comando é: getElementsByClassname

Por seletor de CSS

O comando é: querySelector
